# API-kildekode

Implementasjon av REST API, autentisering, spilldata og kommunikasjon med database og AI. [Modulplanen for WBS 4.1](../../spec/backend-module.md) beskriver krav, komponenter, tester og drift. Python/FastAPI er valgt; implementasjon følger i WBS 4.2 etter den felles implementeringsplanen.

Frontend bruker den felles [utviklerguiden](../../../spec/contracts/webapp-backend/contract.md) og [OpenAPI-kontrakten](../../../spec/contracts/webapp-backend/openapi.yaml). Tester ligger under backend/tests. Ingen API-kode er implementert ennå.
