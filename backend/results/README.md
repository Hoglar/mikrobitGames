# Lokale resultater

Utvalgte testresultater, benchmarks og modelluttrekk. Oppgi dato, commit, krav eller modell, metode, testmiljø, forventet og faktisk resultat samt avvik. Målinger skal ha enheter og relevant konfigurasjon. Behold tidligere iterasjoner, og lenk til resultater som inngår i prosjektets felles FoM.

Etter [implementeringsplanen](../spec/implementation-plan.md) skal hver kjøring gi maskinlesbare råresultater og en kort rapport med kontrollstatus, modellavvik og benchmark. Ta med kodecommit, kontroll-/spesifikasjonsversjon, datasett og modellens digest, runtime og innstillinger. Behold ufullstendige kjøringer med årsak; bare komplette målinger gir FoM-punkt under [results/fom](../../results/fom/README.md). Ingen målinger er gjennomført ennå.
