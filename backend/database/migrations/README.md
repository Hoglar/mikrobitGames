# Databaseendringer

Versjonerte PostgreSQL 17-endringer, inkludert skjema, visninger og tilgangsrettigheter. Første migrering er `001_initial.sql`. Kjør filene i filnavnrekkefølge på en tom database med separat migreringsrolle; tjenestene har ingen skjemarettigheter. Se [databaseveiledningen](../README.md).
