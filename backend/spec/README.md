# Krav, modeller og testplan

Utarbeid requirements.md med funksjonelle krav og kvalitetskrav, og test-plan.md med testtilfeller, forventede resultater og verifikasjonsmetode. Disse dokumentene er ikke ferdigstilt ennå. Modeller lagres under [models/](models/README.md). Backend samler krav for API, database og AI her, med prefiksene BE, DB og AI. Interne kontrakter ligger under [contracts/](contracts/README.md).

- [WBS 1.4 – kort oversikt og kontrakt](contracts/backend-database/README.md).
- [WBS 1.5 – kort kontrakt mellom API og AI-tjenesten](contracts/backend-ai/contract.md).
- [WBS 1.6 – kontrakt mellom AI-tjenesten og databasen](contracts/ai-database/contract.md).
- [Plan for enhetstester og verifisering av backend–database](contracts/backend-database/verification-plan.md).
- [Arbeidsflyt for iterativ utvikling, tester og FoM](iterative-development.md).

De felles backend-dokumentene skal referere til dette grunnlaget, fremfor å kopiere de samme kravene og testforventningene.
