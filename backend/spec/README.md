# Krav, modeller og testplan

Utarbeid requirements.md med funksjonelle krav og kvalitetskrav, og test-plan.md med testtilfeller, forventede resultater og verifikasjonsmetode. Disse dokumentene er ikke ferdigstilt ennå. Modeller lagres under [models/](models/README.md). Backend samler krav for API, database og AI her, med prefiksene BE, DB og AI. Interne kontrakter ligger under [contracts/](contracts/README.md).
