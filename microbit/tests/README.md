# Lokale tester

Enhetstester og tester av samspillet mellom interne komponenter. Følg [testplanen](../spec/test-plan.md) for tilkoblede maskinvaretester og referer til relevante krav. Maskinvaretestene skal markeres som skipped når ingen micro:bit er tilkoblet. Tester mellom hoveddelene ligger under tests i repositoryets rot. Ingen kjørbare tester er implementert ennå.
