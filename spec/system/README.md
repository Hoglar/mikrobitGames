# Systemspesifikasjon

Overordnet arkitektur og krav som gjelder hele systemet. [C4-modellen](models/c4-container.drawio) ligger under models.

Systemkrav utarbeides i requirements.md, og felles integrasjons- og verifikasjonsplan i verification-plan.md under WBS 7.1. Disse dokumentene er ikke utarbeidet ennå. Planen skal beskrive testmiljø, scenarioer, forventede resultater og ansvar for gjennomføring.
