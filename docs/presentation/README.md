# Presentasjon og demonstrasjon

Materiale for fem slides, en video på 30 sekunder og demonstrasjon innenfor totalt 10 minutter. Samle presentasjon, demonstrasjonsoppsett og eventuelle lenker til store videofiler her. Bruk dokumenterte målinger fra results/fom og verifikasjonsresultater.

[Iterativ utvikling – draw.io-diagram](iterative-development.drawio) viser ansvaret til brukeren, utviklings-AI og kontrollverktøyene. Det beskriver den planlagte prosessen og kan brukes til å forklare arbeidsmåten på slide 2–3. Faktiske kurver og resultater legges til etter gjennomførte målinger.
