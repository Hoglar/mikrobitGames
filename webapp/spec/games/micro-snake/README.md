# Micro Snake

Klassisk Snake styrt med Micro:bit V2. Standard, Hurtig og Labyrint har hver Competitive og Random, med seks separate topplister. Flest matbiter rangeres først, deretter færrest bevegelsessteg. Selvvalgt seed gir lokal øving.

**Status:** Avklart funksjonelt omfang og foreslått design, 2026-10-29. Ingen spillimplementasjon eller produktmålinger foreligger. Brettoppsett, balanse og algoritmedetaljer er forslag til kontroll og spilltesting.

- [Game design](game-design.md): brett, bevegelse, mat, progresjon og tilbakemelding.
- [Teoretisk implementasjon](implementation-design.md): tilstander, algoritmer og plattformintegrasjon.
- [Testplan](test-plan.md): scenarioer og forventede resultater.
