# Micro:bit Testlab

Fri testflate for å undersøke om handlinger på Micro:bit samsvarer med nettleserens tolkning, og prøve output fra nettleseren til enheten.

**Status:** Spesifikasjon og foreslått design, 2026-10-27. Ingen implementasjon eller målinger er gjennomført.

- [Spesifikasjon](specification.md): formål, funksjoner og krav.
- [Teoretisk implementasjon](implementation-design.md): komponenter og samspill.
- [Testplan](test-plan.md): scenarioer og forventede resultater.
