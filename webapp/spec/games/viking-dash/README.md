# Viking Dash

En 2D endless runner der en viking hopper og dukker gjennom norske landskap og norrøne hendelser. Målet er lengst mulig distanse. Spillet har rangert modus med tilfeldig seed og øving med selvvalgt seed.

**Status:** Spesifikasjon og foreslått design, 2026-10-28. Funksjonelt omfang er avklart med brukeren. Balanseverdier er forslag til utprøving; spillet er ikke implementert eller verifisert.

- [Game design](game-design.md): fysikk, hindringer, progresjon, miljøer og hendelser.
- [Teoretisk implementasjon](implementation-design.md): spillogikk, seed og plattformintegrasjon.
