# Lokale tester

Enhetstester og tester av samspillet mellom interne komponenter. Følg [testplanen](../spec/test-plan.md) og referer til relevante krav. Kun tester som krever fysisk micro:bit skal hoppes over når kortet ikke er tilkoblet; enhetstester og tester med fake transport skal fortsatt kjøres. Tester mellom hoveddelene ligger under tests i repositoryets rot. Ingen kjørbare tester er implementert ennå.
